## 🌟 Overview

From the birth of the modern automobile to movable-type printing and the discovery of X-rays, Germany has been a global crucible of technological innovation. **Famous German Inventions** is an interactive multi-page static web application providing historical context, technical breakdowns, and biographies of visionary inventors.

---

## 🚀 Key Highlights

- **🚗 Karl Benz & The Automobile**: The 1886 Benz Patent-Motorwagen — the internal combustion engine revolution.
- **📖 Johannes Gutenberg & The Printing Press**: Movable metal type in Mainz (c. 1440) that transformed human literacy.
- **⚡ Wilhelm Röntgen & X-Rays**: The accidental 1895 discovery of electromagnetic radiation that revolutionized diagnostic medicine.
- **🖼️ Interactive Image Gallery**: Curated archival imagery documenting patents, prototypes, and milestones.
- **📱 Responsive & Clean Design**: Elegant typographic styling and straightforward navigation.
